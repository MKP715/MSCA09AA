# docs/

Almost everything the site links to now lives in the Area's Google Drive, not
in this repository — see the "Files live in Google Drive" section of the
repository README.

Only one thing is still kept here:

```
archive/pages/    58 posts that only ever existed as web pages —
                  the Delegate's sharing sessions and G.S.O. announcement
                  round-ups, 2020-2024
```

They stay because Google Drive hands an `.html` file to the browser as a
**download** rather than rendering it as a page. These are pages, not
documents, so they are served from here where they open and read normally.
Together they are about 2 MB.

Everything else — 1,771 minutes, newsletters, financial reports, conference
papers, guidelines and event flyers — is in Drive, addressed by file id from
`data/documents.csv` and `data/events.csv`.
