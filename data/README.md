# Data files

These CSVs are the site's content. Edit them on github.com and the site
updates itself — no build step.

**Anonymity: first name + last initial only, role-based service e-mail
addresses only. No personal e-mail, no phone numbers, no home addresses,
no sobriety dates, no home groups.** Everything here is public and
permanent. See the anonymity section of the repository README.

`calendar.ics` is a mirror of the Area's Google Calendar and is refreshed
automatically — change meetings in Google Calendar, not in this file.
